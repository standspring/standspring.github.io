## 들어가며

버튼이 화면에 보이는데 `locateOnScreen()`이 찾지 못한다면, 먼저 **검색할 파일을 읽을 수 있는지, 캡처와 현재 화면의 배율이 같은지, 검색 영역에 버튼이 들어 있는지** 확인한다. 인식 임계값인 `confidence`부터 낮추면 다른 버튼을 잘못 선택할 수 있다.

이 글은 Windows의 주 모니터에서 사용하는 이미지 기반 자동화를 설명한다. 마우스·키보드의 기본 조작은 [PyAutoGUI 시작하기]({% post_url 2026-02-28-pyautogui_guide %}), 창 이동과 활성화는 [PyGetWindow로 대상 창 제어하기]({% post_url 2026-03-01-pyautogui_pygetwindow_guide %})에서 이어서 볼 수 있다.

## 문제 상황: 이미지를 못 찾았는데 대기 루프가 종료된다

다음 패턴은 이미지가 없을 때 항상 `None`이 반환된다고 가정한다.

```python
location = pyautogui.locateOnScreen("button.png", confidence=0.9)
if location is None:
    print("다음 검색까지 기다립니다.")
```

하지만 [공식 스크린샷 문서](https://pyautogui.readthedocs.io/en/latest/screenshot.html)는 이미지를 못 찾으면 `ImageNotFoundException`이 발생하는 동작을 안내한다. 이 경우 `if`까지 도달하지 못한다. 설치 버전과 설정에 따라 `None`을 받는 코드도 있으므로 두 경우를 구분해 처리하자.

또한 **파일을 읽지 못하는 오류와 화면에서 매칭되지 않는 오류는 다르다.** 잘못된 파일 경로까지 이미지 미검출로 처리하면 재시도만 반복하게 된다.

## 원인 분석: 파일·화면·검색 조건을 나누어 확인한다

| 확인 순서 | 증상 또는 조건 | 먼저 할 일 |
|---|---|---|
| 1. 파일 경로 | 파일을 읽지 못한다 | 이미지의 절대경로와 파일 존재 여부 확인 |
| 2. 화면 상태 | 다른 창에 가려졌거나 최소화됐다 | 대상 창을 보이게 한 뒤 스크린샷 확인 |
| 3. 배율·크기 | 다른 PC나 모니터에서만 실패한다 | 같은 Windows 배율·앱 확대율에서 다시 캡처 |
| 4. 검색 영역 | 전체 화면에서는 되는데 `region`에서 실패한다 | 화면 기준 좌표와 영역 크기 확인 |
| 5. 매칭 조건 | 비슷한 버튼을 잘못 찾는다 | 식별 가능한 이미지 사용, 임계값과 색상 조건 비교 |

`confidence=0.9`는 인식 성공 확률이 90%라는 뜻이 아니다. OpenCV의 이미지 매칭 결과를 걸러내는 임계값이며, 값만으로 업무상 오인식 확률을 알 수 없다.

## 해결 방법: 예외 처리와 제한 시간을 함께 둔다

설치는 같은 Python 환경에서 진행한다.

```powershell
python -m pip install pyautogui opencv-python
python -m pip show PyAutoGUI PyScreeze opencv-python Pillow
```

아래 코드를 `wait_image.py`로 저장한다. 기본 실행은 **위치 확인만** 하며, `--click`을 지정할 때 한 번 클릭한다.

```python
import argparse
import logging
from pathlib import Path
import time

import pyautogui


def wait_for_image(image, *, timeout=10.0, interval=0.3,
                   confidence=0.9, region=None):
    image = Path(image).resolve()
    if not image.is_file():
        raise FileNotFoundError(image)
    if timeout <= 0 or interval <= 0:
        raise ValueError("timeout과 interval은 양수여야 합니다.")
    if not 0 < confidence <= 1:
        raise ValueError("confidence는 0보다 크고 1 이하여야 합니다.")
    if region is not None:
        if len(region) != 4 or region[2] <= 0 or region[3] <= 0:
            raise ValueError("region은 (left, top, 양수 width, 양수 height)입니다.")

    deadline = time.monotonic() + timeout
    attempts = 0
    while True:
        attempts += 1
        try:
            location = pyautogui.locateOnScreen(
                str(image), confidence=confidence, region=region,
                grayscale=False,
            )
        except pyautogui.ImageNotFoundException:
            location = None

        if location is not None:
            logging.info("found attempts=%d box=%s", attempts, location)
            return location

        remaining = deadline - time.monotonic()
        if remaining <= 0:
            raise TimeoutError(
                f"이미지 미검출: {image.name}, attempts={attempts}, region={region}"
            )
        time.sleep(min(interval, remaining))


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("image")
    parser.add_argument("--timeout", type=float, default=10.0)
    parser.add_argument("--confidence", type=float, default=0.9)
    parser.add_argument("--region", type=int, nargs=4)
    parser.add_argument("--click", action="store_true")
    args = parser.parse_args()

    logging.basicConfig(level=logging.INFO, format="%(levelname)s %(message)s")
    pyautogui.FAILSAFE = True
    pyautogui.PAUSE = 0.2
    box = wait_for_image(
        args.image, timeout=args.timeout, confidence=args.confidence,
        region=tuple(args.region) if args.region is not None else None,
    )
    point = pyautogui.center(box)
    print(f"center=({point.x}, {point.y}), click={args.click}")
    if args.click:
        pyautogui.click(point.x, point.y)


if __name__ == "__main__":
    main()
```

일시적인 미검출만 재시도한다. 파일 읽기 오류나 `FailSafeException`은 호출자에게 전달되므로 다른 원인을 대기 루프로 숨기지 않는다.

`time.monotonic()`으로 경과 시간을 계산한다. 다만 이미지 검색 자체를 중단하는 타이머는 아니므로, 검색 한 번이 오래 걸리면 지정한 시간보다 늦게 반환할 수 있다.

## 예제: 먼저 클릭하지 않고 위치를 확인한다

```powershell
python wait_image.py .\button.png --timeout 5
python wait_image.py .\button.png --region 100 200 800 600 --timeout 5
```

`region`은 **화면 전체를 기준으로 한 왼쪽·위쪽·너비·높이**다. 오른쪽·아래쪽 좌표나 창 내부 상대좌표가 아니다. 창 내부에서 정한 위치를 사용한다면 창의 왼쪽·위쪽 좌표를 더해 화면좌표로 바꾼다.

검색 범위를 좁히면 처리 시간을 줄일 수 있지만 개선 폭은 화면 크기·이미지·환경에 따라 달라진다. `grayscale=True`도 비교할 수 있으나 색으로 구분하는 버튼을 잘못 인식할 수 있다. 고정된 향상 배수나 성공률 대신 실제 화면에서 측정하자.

## 결과 확인: 화면 조작 없이 이미지 매칭을 재현한다

다음은 실제 화면 대신 메모리상에서 만든 이미지로 일치 위치를 검증하는 독립 예제다. 마우스 조작이나 창 표시는 하지 않는다.

```python
import random

from PIL import Image
import pyscreeze

rng = random.Random(7)
pixels = bytes(rng.randrange(256) for _ in range(40 * 30 * 3))
template = Image.frombytes("RGB", (40, 30), pixels)
canvas = Image.new("RGB", (240, 160), (20, 30, 40))
canvas.paste(template, (80, 50))

box = pyscreeze.locate(template, canvas, confidence=0.99, grayscale=False)
print("matched:", tuple(int(value) for value in box))

other = Image.frombytes(
    "RGB", (40, 30),
    bytes(rng.randrange(256) for _ in range(40 * 30 * 3)),
)
try:
    missing = pyscreeze.locate(other, canvas, confidence=0.99, grayscale=False)
except pyscreeze.ImageNotFoundException:
    print("missing: ImageNotFoundException")
else:
    print("missing:", missing)
```

Python 3.14.5, PyScreeze 1.0.1, OpenCV 4.13.0.92, Pillow 12.2.0에서 확인한 출력:

```text
matched: (80, 50, 40, 30)
missing: ImageNotFoundException
```

이 결과는 이미지 매칭 확인이며, 실제 앱의 인식률이나 클릭 성공률을 나타내지 않는다. `wait_image.py`의 재시도·시간 초과·입력값 검증은 화면 검색을 대체해 확인했다. 실제 화면의 검색 영역과 조작 위치는 사용하는 PC에서 확인해야 한다.

## 실무 팁

### 흔한 실수

- `except Exception`으로 모든 오류를 무시하고 계속 재시도한다.
- 화면을 확인하기 전에 `confidence`부터 낮춘다.
- 후보 좌표를 모두 저장한 뒤 클릭하면서 화면이 바뀐 것을 놓친다.

`locateAllOnScreen()`은 이터레이터를 반환하므로 `list(...)`로 변환하는 과정도 예외 처리 범위에 넣는다. 클릭으로 화면이 바뀐다면 다음 대상은 다시 검색한다.

### 주의사항

주 모니터의 모서리로 마우스를 옮겨 동작을 중단할 수 있도록 페일세이프를 유지한다. 화면 잠금이나 비대화형 세션의 문제는 이미지 정확도를 조정해도 해결되지 않는다. [작업 스케줄러의 로그온 조건]({% post_url 2026-03-06-task_scheduler %})도 확인하자.

### 추천 명령어

```powershell
python wait_image.py .\button.png --confidence 0.9 --timeout 5
```

실제 클릭은 위치를 확인한 뒤 `--click`을 붙여 실행한다.

## 마무리

### 핵심 요약

이미지 파일·표시 상태·검색 영역을 확인하고 일시적인 미검출만 재시도한다. 검색과 클릭을 분리하면 잘못된 위치를 조작하기 전에 결과를 확인하기 쉽다.
