# 2026 AI 플랫폼 종류와 구독 가격 비교

![대화, 문서 작성, 검색, 사무 작업, 코딩, 이미지 제작용 AI 도구와 구독 기능을 비교하는 노트북 일러스트](/assets/img/2026-10-04-ai-platform-subscription-pricing-comparison.png)

## 들어가며

AI 서비스를 고를 때 가장 먼저 떠오르는 질문은 두 가지입니다. **어떤 서비스가 내 작업에 맞을까? 그리고 한 달에 얼마가 들까?**

이 글에서는 개인이 구독할 수 있는 대표적인 AI 플랫폼 8개를 비교합니다. 글쓰기와 대화용 서비스뿐 아니라 검색, 사무 문서, 코딩, 이미지 제작에 초점을 맞춘 서비스도 함께 살펴봅니다.

**가격 확인 기준일은 2026년 10월 4일입니다.** 비교 기준은 공식 페이지에 표시된 미국 달러(USD) 기준 웹 구독의 월 결제 가격입니다. 한국의 원화 결제 가격을 뜻하지 않으며, 세금·환율·결제 수수료·앱스토어 가격에 따라 실제 청구액은 달라질 수 있습니다. 무료 체험과 일시적인 프로모션은 표의 기본 가격에서 제외했습니다.

모든 AI 서비스를 망라한 목록은 아닙니다. 기업용 계약과 개발자 API의 토큰 단가는 개인 구독과 과금 방식이 달라 비교 대상에서 제외했습니다.

## 문제 상황

### 월 20달러짜리 AI는 모두 같은 상품일까?

ChatGPT Plus, Claude Pro, Perplexity Pro, Cursor Pro는 모두 월 20달러이지만, 실제로 비용을 지불하는 대상은 다릅니다.

- ChatGPT는 대화·분석·생성 작업을 함께 처리하는 범용 작업 공간에 가깝습니다.
- Claude는 문서와 코드 작업, 프로젝트 단위의 협업 기능을 제공합니다.
- Perplexity는 웹 자료를 찾고 출처를 따라가며 조사하는 흐름에 초점을 맞춥니다.
- Cursor는 코드 편집 환경 안에서 AI를 사용하는 개발 도구입니다.

따라서 가격이 같다고 해서 기능이나 사용량이 같다고 볼 수 없습니다. 아래에서 각 서비스의 공식 요금제와 차이를 확인해 봅니다.

## 원인 분석

### AI 모델과 AI 플랫폼은 구분해야 한다

AI 모델은 답변을 생성하는 엔진이고, AI 플랫폼은 그 엔진을 이용해 검색·파일 분석·편집·자동화 등을 제공하는 서비스입니다.

예를 들어 Cursor와 Perplexity는 여러 공급사의 모델을 지원합니다. 그렇더라도 이 서비스를 구독한다고 ChatGPT나 Claude의 별도 유료 계정을 함께 받는 것은 아닙니다. 이용 가능한 모델과 기능은 해당 플랫폼의 계약과 사용량 정책을 따릅니다. [Cursor 공식 문서](https://prod.cursor.com/docs/models-and-pricing), [Perplexity 공식 요금 안내](https://www.perplexity.ai/enterprise/pricing)

### 구독료 외에 사용량 구조도 다르다

서비스마다 제한을 계산하는 기준이 다릅니다. 대화 길이와 작업 복잡도에 따라 한도가 소모되기도 하고, AI 크레딧이나 GPU 시간으로 사용량을 계산하기도 합니다.

**비싼 요금제를 선택해도 모든 기능을 제한 없이 사용할 수 있다고 단정하면 안 됩니다.** 구독료, 포함 사용량, 한도 초기화 주기, 추가 사용료를 함께 확인해야 합니다.

### 1. ChatGPT: 여러 종류의 작업을 한곳에서 처리

ChatGPT는 글 작성과 질문 답변뿐 아니라 파일을 활용한 작업과 코딩을 함께 검토할 때 비교할 만한 플랫폼입니다.

- Free와 Go에는 가벼운 코딩 작업을 위한 제한적인 Codex 접근이 포함됩니다.
- Plus에는 웹·CLI·IDE 확장 등에서 사용하는 Codex와 추가 사용을 위한 크레딧 구매 옵션이 포함됩니다.
- Pro는 월 $100, $200, $500의 세 사용량 단계로 나뉩니다.
- ChatGPT Work와 Codex는 사용량을 공유하므로, 두 기능을 각각 독립된 무제한 한도로 생각하면 안 됩니다.
- API 키로 사용하는 개발자 API 요금은 구독 사용량과 별도입니다.

**여러 작업을 하나의 구독으로 묶고 싶은 사람**이 먼저 살펴볼 후보입니다. 코딩 기능을 많이 쓴다면 결제 전 현재 계정의 사용량 화면도 확인하는 편이 좋습니다. [OpenAI 공식 문서: 가격과 포함 기능](https://learn.chatgpt.com/docs/pricing)

### 2. Claude: 문서와 코드 작업을 프로젝트로 연결

Claude는 문서 작성과 프로젝트 자료 활용, 개발 작업을 함께 진행하려는 사람에게 비교할 만한 서비스입니다.

- Free에서 웹 검색, 코드 실행, Artifacts 생성 등을 제공합니다.
- Pro에는 Projects와 Claude Code, 문서·슬라이드 제작 기능 등이 포함됩니다.
- Pro의 월 결제는 $20이고, 연 결제는 **$200 선결제**입니다. 연간 금액을 12로 나누면 약 $16.67입니다.
- Max 5x는 월 $100, Max 20x는 월 $200입니다. 여기서 배수는 Pro 대비 사용량을 가리키며 답변 품질이 그만큼 높아진다는 뜻이 아닙니다.
- Max에도 세션 및 주간 사용량 한도가 있습니다.

**자료를 프로젝트별로 정리하거나 터미널에서 Claude Code를 쓰려는 사람**에게 확인할 가치가 있습니다. [Claude 공식 가격](https://claude.com/pricing), [Max 사용량·결제 안내](https://support.claude.com/en/articles/11049741-what-is-the-max-plan)

### 3. Gemini: Google 서비스와 저장 공간까지 함께 비교

Gemini의 개인 유료 이용권은 Google AI Plus·Pro·Ultra 구독으로 제공됩니다. AI 기능과 저장 공간을 묶어 비교하는 것이 핵심입니다.

- 무료 Gemini에서도 이미지 생성·편집, Deep Research, Gemini Live 등 일부 기능을 이용할 수 있습니다.
- AI Plus는 월 $4.99이며 400GB 저장 공간과 더 높은 사용량을 제공합니다.
- AI Pro는 월 $19.99이며 5TB 저장 공간과 Google 앱 연계 등 확장 기능을 제공합니다.
- AI Ultra는 월 $99.99와 $199.99 단계로 나뉘며, 공식 표에서는 AI Pro 대비 각각 5배·20배의 사용량을 안내합니다.
- 생성 도구의 크레딧, 부가 혜택, 지원 기능은 요금제와 국가에 따라 다릅니다.

**Gmail·Google 문서·Drive를 자주 쓰는 사람**은 AI 기능뿐 아니라 현재 지출하는 저장 공간 비용까지 함께 비교할 수 있습니다. 위 금액과 혜택은 미국 페이지 기준이며, 한국 계정의 제공 조건은 별도로 확인해야 합니다. [Gemini 공식 구독 안내](https://gemini.google/subscriptions/)

### 4. Perplexity: 답변에서 원문 자료로 이동하는 조사 도구

Perplexity는 검색 결과를 바탕으로 답변과 출처를 연결하는 서비스입니다.

- Free는 간단한 질문과 기본 검색을 시험하는 용도로 사용할 수 있습니다.
- Pro는 월 $20이며 Deep Research와 모델 선택, 문서·앱 제작 등 확장 기능을 제공합니다.
- Max는 월 $200이며 더 높은 사용량과 고급 조사 기능을 제공합니다.
- 유료 플랜에서도 검색·파일 업로드·생성 기능별 한도가 적용됩니다.
- API는 웹·앱 구독과 별도로 과금됩니다.

**뉴스나 기술 자료를 조사하면서 근거 링크를 따라가야 하는 사람**에게 비교할 만합니다. 출처가 붙어 있어도 해당 문장이 원문 내용과 일치하는지는 직접 읽어 확인해야 합니다. [Perplexity 공식 가격](https://www.perplexity.ai/enterprise/pricing), [개인·기업 플랜 비교](https://www.perplexity.ai/help-center/en/articles/11187416-which-perplexity-subscription-plan-is-right-for-you)

### 5. Microsoft Copilot: Office 사용 비용과 함께 계산

Microsoft Copilot은 개인용 Microsoft 365 구독에 포함된 AI 기능을 중심으로 살펴보면 이해하기 쉽습니다.

- Personal은 월 $9.99로, 1인용 Office 앱과 1TB 저장 공간, Copilot 기능을 제공합니다.
- Family는 월 $12.99로 최대 6명이 앱과 저장 공간을 이용할 수 있습니다.
- Premium은 월 $19.99로 고급 Copilot 기능과 더 높은 사용량을 제공합니다.
- Microsoft 365 Pro는 월 $99.99로 더 높은 AI 사용량을 제공합니다.
- **Family 등 가족 구독의 AI 혜택은 구독 소유자에게만 제공됩니다.** 가족 모두에게 같은 Copilot 권한이 생긴다고 계산하면 안 됩니다.

Word·Excel·PowerPoint를 이미 사용한다면 별도의 AI 구독을 추가하기 전에 현재 Microsoft 365 플랜에 포함된 기능을 먼저 확인할 수 있습니다. **Microsoft Copilot과 개발 도구인 GitHub Copilot은 별개의 서비스**입니다. [Microsoft 공식 개인용 가격·기능 비교](https://www.microsoft.com/en-us/copilot/pricing/individuals)

### 6. Grok: 웹과 X의 정보를 함께 탐색

Grok은 공식 기능 목록에서 실시간 웹 검색과 X 검색을 함께 내세웁니다.

- Free에서 웹·X 검색과 음성 등 기본 기능을 제공합니다.
- SuperGrok은 월 $30으로 더 높은 한도, 고급 모델 접근, 이미지·영상 생성 등을 제공합니다.
- SuperGrok Plus는 월 $100으로 더 높은 사용량, 1080p 영상 생성, 우선 접근 등을 제공합니다.

**X에서 형성되는 반응과 웹 자료를 함께 살펴보는 사람**이 비교할 만합니다. 게시물에서 발견한 주장과 공식 발표를 구분하는 습관이 필요합니다. [Grok 공식 가격·기능](https://x.ai/pricing)

### 7. Cursor: 코드를 작성하는 환경 자체에 AI를 결합

Cursor는 범용 챗봇과 달리 코드 편집기를 중심으로 AI 작업을 연결합니다.

- Hobby로 제한적인 무료 기능을 시험할 수 있습니다.
- Pro는 월 $20, Pro+는 월 $60, Ultra는 월 $200입니다.
- 유료 개인 플랜에는 코드 자동 완성, 확장된 Agent 사용량, Cloud Agents 등이 포함됩니다.
- 지원 모델에 따라 포함 사용량의 소모 속도가 달라집니다.
- 포함량을 넘으면 상위 플랜이나 추가 사용량 과금을 선택할 수 있습니다.

**편집기 안에서 코드 수정과 개발 작업을 이어 가려는 사람**에게 적합한 후보입니다. 자동 완성의 무제한 제공과 모든 Agent 작업의 무제한 제공은 구분해서 읽어야 합니다. [Cursor 가격](https://cursor.com/pricing), [사용량과 추가 과금](https://prod.cursor.com/docs/models-and-pricing)

### 8. Midjourney: 이미지 제작량과 공개 여부가 선택 기준

Midjourney는 이미지·영상 제작에 초점을 맞춘 서비스입니다. 요금제를 고를 때 생성 횟수만 보기보다 GPU 시간과 생성 모드를 확인해야 합니다.

| 요금제 | 월 결제 | 연 결제 총액 | 연 결제 월 환산액 |
|---|---:|---:|---:|
| Basic | $10 | $96 | $8 |
| Standard | $30 | $288 | $24 |
| Pro | $60 | $576 | $48 |
| Mega | $120 | $1,152 | $96 |

- Fast GPU 시간은 Basic 3.3시간, Standard 15시간, Pro 30시간, Mega 60시간입니다.
- Standard 이상은 Relax Mode의 무제한 이미지 생성을 제공합니다.
- Pro와 Mega는 Relax Mode의 무제한 영상 생성을 제공합니다.
- 생성물을 비공개로 유지하는 Stealth Mode는 Pro와 Mega에서 제공합니다.
- 연 결제는 1년 금액을 선결제하며 월 결제 대비 20% 할인됩니다.

**블로그 삽화나 시각 콘셉트를 반복 제작하는 사람**이 비교할 만합니다. 연간 구독 화면의 월 환산액을 매달 청구되는 금액으로 오해하지 않도록 주의해야 합니다. [Midjourney 공식 플랜 비교](https://docs.midjourney.com/hc/en-us/articles/27870484040333-Comparing-Midjourney-Plans)

### 어떤 플랫폼부터 시험하면 좋을까?

아래는 공식 기능을 바탕으로 한 용도별 선택 제안입니다. 성능 순위나 직접 수행한 벤치마크 결과는 아닙니다.

| 내가 자주 하는 작업 | 먼저 비교할 후보 | 실제로 확인할 부분 |
|---|---|---|
| 글쓰기·학습·파일 작업을 폭넓게 처리 | ChatGPT, Claude, Gemini | 한국어 수정 품질, 파일 처리, 원하는 결과 형식 |
| 최신 자료 조사와 출처 확인 | Perplexity, Gemini | 원문 접근성, 인용 정확성, 조사 한도 |
| Google 문서와 메일 활용 | Gemini | 내 국가·계정의 앱 연계와 저장 공간 |
| Office 문서와 표 작업 | Microsoft Copilot | 현재 구독 포함 기능과 소유자 권한 |
| 코딩과 저장소 수정 | Cursor, Claude Code, Codex | 편집기·터미널 적합성, 수정 검토, 사용량 |

| 이미지·영상 제작 | Midjourney | 생성 모드, GPU 시간, 공개·비공개 조건 |

## 예제

### 같은 작업으로 무료 기능을 비교하기

서비스마다 다른 질문을 던지면 비교가 어렵습니다. 같은 자료와 요구사항으로 결과를 확인해 보는 편이 좋습니다.

```text
다음 회의 메모를 바탕으로 업무 보고서 초안을 작성해줘.
결정 사항, 담당자, 마감일, 아직 결정되지 않은 항목을 구분해줘.
메모에 없는 담당자나 날짜는 추측하지 말고 '확인 필요'라고 표시해줘.
마지막에는 확인 질문을 3개 이내로 정리해줘.

[같은 회의 메모를 붙여넣기]
```

이 예제에서는 문장의 자연스러움뿐 아니라 **정보를 지어내는지, 지정한 형식을 지키는지, 후속 수정이 쉬운지**를 확인합니다. 실제 비교 결과를 기록하면 유료 전환의 이유도 분명해집니다.

### 구독을 여러 개 사용할 때의 비용 계산

ChatGPT Plus와 Cursor Pro, Midjourney Basic을 함께 월 결제로 사용한다고 가정하면 세금과 추가 사용료를 제외한 기본 비용은 월 $50입니다.

다음 Python 코드는 이 가정의 월·연 비용을 계산합니다.

```python
plans_usd = {
    "ChatGPT Plus": 20,
    "Cursor Pro": 20,
    "Midjourney Basic": 10,
}

monthly = sum(plans_usd.values())
print(f"Monthly base cost: ${monthly:.2f}")
print(f"12 months at monthly rates: ${monthly * 12:.2f}")
```

## 결과 확인

위 코드를 `ai_subscription_cost.py`로 저장한 뒤 실행할 수 있습니다.

```bash
python ai_subscription_cost.py
```

실행 결과는 다음과 같습니다.

```text
Monthly base cost: $50.00
12 months at monthly rates: $600.00
```

연간 $600은 **월 결제를 12개월 유지한다는 가정**입니다. 연 결제 할인이나 추가 사용료를 반영한 금액은 아닙니다.

플랫폼 선택도 같은 방식으로 확인하면 됩니다. 후보 서비스를 같은 작업에 사용해 보고, 결과 수정에 걸린 시간과 한도에 도달한 빈도를 기록합니다. 무료 기능으로 충분하다면 유료 구독을 바로 추가할 필요가 없습니다.

## 실무 팁

### 흔한 실수

- **연 결제 월 환산액과 월 청구액을 혼동하기:** Claude Pro의 연 $200은 매달 약 $16.67을 내는 상품이 아니라 연간 금액을 한 번에 내는 상품입니다.
- **같은 이름의 Pro를 같은 등급으로 생각하기:** 플랫폼마다 기능과 사용량 기준이 다릅니다.
- **같은 모델을 지원하면 원래 서비스의 기능도 모두 제공된다고 생각하기:** 모델 접근과 제품 기능은 별개입니다.
- **추가 사용량 과금을 기본 구독료에 포함된 것으로 생각하기:** Agent나 크레딧 기반 작업은 지출 설정도 확인해야 합니다.
